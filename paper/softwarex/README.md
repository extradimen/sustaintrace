# SoftwareX Manuscript

This directory contains the English, publication-facing SustainTrace manuscript prepared with the
official Elsevier CAS single-column template.

- `SustainTrace_SoftwareX_Manuscript.tex` — manuscript source
- `references.bib` — bibliographic source retained for reference management
- `cas-sc.cls`, `cas-common.sty`, `cas-model2-names.bst` — official template dependencies
- `sustaintrace-*.png` — manuscript figures
- `SustainTrace_Claim_Boundaries_v1.0.md` — explicit claim and interpretation boundaries
- `OFFICIAL_TEMPLATE_RECEIPT.md` — template provenance
- `SOFTWAREX_STRUCTURE_REVIEW.md` — structural review against SoftwareX conventions

The compiled manuscript cites the immutable GitHub/Zenodo release once its DOI is assigned.
