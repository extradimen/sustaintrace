# SoftwareX submission checklist

## Manuscript and scientific scope

- [x] Official Elsevier CAS single-column LaTeX class is included.
- [x] Title and abstract describe executable research software rather than a general AI method.
- [x] Abstract is 110 words.
- [x] Six keywords are supplied.
- [x] Five principal SoftwareX sections are used: Motivation and significance, Software
  description, Illustrative examples, Impact, and Conclusions.
- [x] The manuscript is below 4,000 words and contains four figures.
- [x] RQ1, RQ2 and RQ3 use distinct denominators and explicit claim boundaries.
- [x] Limitations report full-claim fidelity, false abstention, model-dependent over-blocking and
  the bounded scope of repair evidence.
- [x] The manuscript does not claim external verification of issuer disclosures or general
  autonomous code self-modification.
