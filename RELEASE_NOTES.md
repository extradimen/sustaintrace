# SustainTrace 0.1.1

SustainTrace 0.1.1 is the SoftwareX-aligned immutable public research-software release.

Permanent archive DOI: <https://doi.org/10.5281/zenodo.23293034>

## Included

- cross-platform bootstrap and unified launcher;
- embedded production web workbench;
- 149 reviewed Tier B report facts, 34 controlled entities and 149 relation edges;
- 1,032 failure observations with repair-strategy metadata;
- RQ1 human-adjudicated fidelity artifacts;
- RQ2 paired admission-control artifacts for two cloud models;
- RQ3 immutable component and repair-lifecycle evidence;
- SoftwareX manuscript source, figures and official Elsevier CAS dependencies.

## Distribution boundary

Corporate source PDFs, model weights, credentials, local caches and internal development archives
are not redistributed. Public evaluation artifacts contain derived records, task definitions,
metrics and checksums. See `docs/SOURCE_DISTRIBUTION_POLICY.md`.
